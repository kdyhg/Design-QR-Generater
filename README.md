# Design-QR-Generater

하트·별 등 다양한 외곽 모양으로 꾸민 QR코드 생성기입니다. 별도 서버 없이 브라우저에서 실행됩니다.

## 주요 기능
- URL, 일반 텍스트, Wi-Fi 정보로 QR 생성
- 모양: 사각형·하트·별·원형·꽃·구름·말풍선
- QR 내부 점: 기본 사각형·둥근 사각형·원형 (기능 패턴은 보호)
- 단색·그라데이션·색상 프리셋
- 중앙 로고·이미지 첨부 (PNG/JPG/WEBP/GIF, 최대 2MB)
- 자연스러운 연결형 장식(가장자리에 일부 연결점을 두고 자동 디코딩·축소 이미지 검증, 실패 시 점진적으로 여백 확대)
- 표준 4모듈 여백 모드 선택 가능
- 생성 결과를 번들 jsQR로 자동 디코딩 검증, 색상 대비 경고
- URL 변경 시 QR 자동 갱신
- PNG 저장 해상도 선택(512/1024/2048), 클립보드 복사, 벡터 SVG 내보내기
- URL 최대 30개 일괄 생성 및 ZIP 저장
- 디자인 설정만 로컬 브라우저에 저장·초기화 (URL/텍스트/Wi-Fi 비밀번호/이미지 저장 안 함)

## 실행
index.html 파일을 브라우저로 열면 됩니다. GitHub Pages의 main 루트로 배포할 수도 있습니다.
추가 라이브러리 설치가 필요하지 않으며 QR 생성·디코딩 라이브러리는 vendor 폴더에 포함되어 있습니다.

## 스캔 관련 안내
QR 본체는 오류 정정 H로 생성하며, 위치 탐지·정렬·타이밍 패턴은 그대로 유지합니다. 기본 '자연스럽게 연결' 모드에서는 장식과 QR 사이의 흰띠를 줄이기 위해 1모듈 여백에 소수의 연결점을 더한 모습부터 시도합니다. 원본·축소 이미지 자동 디코딩이 모두 성공하지 않으면 연결점을 제거하고, 여백을 2→3→4모듈로 점차 늘립니다. 별도 '표준 여백 유지(4칸)'를 선택하면 연결점을 사용하지 않고 4모듈 여백을 유지합니다.

**중요:** 자동 연결 모드에서 1~3모듈 여백은 QR 코드의 표준 권장 4모듈 여백보다 좁으므로 실제 카메라나 인쇄물에서 인식이 달라질 수 있습니다. 자동 디코딩에 성공해야 저장·복사 버튼이 활성화되지만, 자동 검증 통과가 모든 휴대전화·인쇄 환경의 스캔 성공을 보증하지 않습니다. 중요한 안내문이나 실물 인쇄물에는 표준 여백 모드를 권장합니다.

로고, 작은 원형 점, 낮은 대비, 그라데이션은 인식에 영향을 줄 수 있습니다. 문제가 있으면 어두운 단색, 밝은 배경, 사각형 모듈, 로고 제거를 시도해 보세요. 실제 사용 전에는 스마트폰으로 확인하세요.

일괄 생성은 URL 전용이며 현재 디자인을 적용합니다. 디코딩 실패한 항목은 ZIP 안의 result.txt에 기록되며 PNG로 저장되지 않습니다.
SVG의 QR 점과 장식은 벡터 도형이며, 로고를 올린 경우에만 로고 이미지 부분이 래스터로 포함됩니다.

## 테스트
Node.js 20 이상에서 실행합니다.

    node --check app.js
    node --test tests/smoke.test.cjs

자동 테스트에서는 URL·Wi-Fi 입력, 필수 여백, 기능 패턴, SVG, ZIP 구조 및 실제 인코딩·디코딩을 확인합니다. 브라우저에서의 파일 업로드와 저장, 모바일 카메라 스캔은 별도로 확인하는 것을 권장합니다.

## 파일 구성
- index.html: 화면/스타일
- app.js: QR 생성·검증·파일 출력
- vendor/: QR 라이브러리와 라이선스
- tests/smoke.test.cjs: Node.js 회귀 테스트
